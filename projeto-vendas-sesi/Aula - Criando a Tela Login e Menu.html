Tela de Login

Autenticando no banco e abrindo o formulário de menu

🎯 Sobre esta aula
Todo o código fica dentro da própria classe da tela (Frmlogin.java). Não vamos criar classes de Model, DAO ou Controller — o botão "Entrar" chama direto um método que consulta o banco. Ao autenticar com sucesso, a tela de login se fecha e o formulário de menu é aberto. É a mesma lógica direta usada na aula de cadastro de clientes, sem orientação a objetos.

2 Criando a tabela de usuários

No mesmo banco db_vendas_sesi, crie a tabela tb_usuarios e insira um usuário de teste:

SQLCREATE TABLE tb_usuarios (
    ID INT AUTO_INCREMENT PRIMARY KEY,
    EMAIL VARCHAR(150),
    SENHA VARCHAR(50)
);

INSERT INTO tb_usuarios (EMAIL, SENHA)
VALUES ('admin@sesi.com', '1234');
💡 Sobre a senha em texto puro
Guardar a senha assim, sem criptografia, é só pra fins didáticos. Num sistema de verdade, a senha nunca fica gravada em texto puro — o correto seria salvar um hash (com bcrypt, por exemplo) e comparar o hash, não o texto.

3 Método de conexão

O Frmlogin também precisa do método conectar() — é o mesmo usado na tela de clientes, só copiar pra dentro dessa classe:

Frmlogin.javaprivate Connection conectar() {
    Connection conexao = null;
    try {
        String url = "jdbc:mysql://localhost:3306/db_vendas_sesi";
        String usuario = "root";
        String senha = ""; // coloque a senha do seu MySQL

        conexao = DriverManager.getConnection(url, usuario, senha);
    } catch (SQLException erro) {
        JOptionPane.showMessageDialog(null, "Erro ao conectar: " + erro.getMessage());
    }
    return conexao;
}
💡 Imports necessários
Igual na aula de clientes: java.sql.Connection, java.sql.DriverManager, java.sql.PreparedStatement, java.sql.ResultSet, java.sql.SQLException e javax.swing.JOptionPane.

4 Botão "Entrar" — validando o login

Duplo clique no botão Entrar no Design pra gerar o evento. A ideia: pesquisar no banco se existe um usuário com aquele EMAIL e SENHA. Se existir, autentica; se não, mostra erro.

Frmlogin.javaprivate void btnEntrarActionPerformed(java.awt.event.ActionEvent evt) {
    String email = txtEmail.getText();
    String senha = new String(txtSenha.getPassword());

    if (email.isEmpty() || senha.isEmpty()) {
        JOptionPane.showMessageDialog(null, "Preencha e-mail e senha.");
        return;
    }

    Connection conexao = conectar();
    if (conexao == null) return;

    try {
        String sql = "SELECT ID FROM tb_usuarios WHERE EMAIL=? AND SENHA=?";

        PreparedStatement stmt = conexao.prepareStatement(sql);
        stmt.setString(1, email);
        stmt.setString(2, senha);

        ResultSet rs = stmt.executeQuery();

        if (rs.next()) {
            // login OK: abre o menu passando o e-mail e fecha a tela de login
            new FrmMenu(email).setVisible(true);
            this.dispose();
        } else {
            JOptionPane.showMessageDialog(null, "E-mail ou senha inválidos.");
            txtSenha.setText("");
        }

        conexao.close();
    } catch (SQLException erro) {
        JOptionPane.showMessageDialog(null, "Erro ao autenticar: " + erro.getMessage());
    }
}
⚠️ Por que "new String(...)" na senha?
JPasswordField.getPassword() devolve um char[], não uma String — é assim por segurança (arrays podem ser "limpos" da memória, Strings não). Como aqui vamos só comparar com o banco, convertemos pra String mesmo, sem se preocupar com isso.

5 Botão "Sair" — encerrando o programa

6 Criando o formulário de menu

Crie um novo JFrame Form no mesmo pacote telas, chamado FrmMenu. É a tela que abre depois do login, e o objetivo é chegar num padrão parecido com este:

Tela de menu que vamos montar nesta aula

Título da janela

Na aba Properties do JFrame, mude a propriedade title para Sistema de Controle de Vendas.

Barra de opções no topo

Arraste um JPanel pro topo da tela, ocupando toda a largura, com um FlowLayout alinhado à esquerda. Dentro dele, coloque um JButton pra cada opção do sistema. Em cada botão, use a propriedade icon pra colocar uma imagem, text pro nome da opção, e horizontalTextPosition = RIGHT pra o texto ficar do lado do ícone.

Deixando os botões "sem cara de botão"

Pra ficar igual ao print (sem moldura, sem fundo cinza), em cada botão da barra desmarque as propriedades borderPainted, contentAreaFilled e focusPainted.

Rodapé com o usuário logado

No rodapé da tela, coloque um JLabel fixo com o texto Usuário Logado: e, ao lado, outro JLabel chamado lblNomeUsuario — é nele que vamos mostrar quem entrou no sistema.

Mostrando o e-mail de quem fez login

Pra tela de menu saber quem logou, vamos fazer o Frmlogin passar o e-mail pra ela na hora de abrir. No FrmMenu, crie um construtor novo que recebe esse e-mail como parâmetro — sem mexer no construtor que o NetBeans já gerou:

FrmMenu.javapublic FrmMenu(String usuarioLogado) {
    initComponents();
    lblNomeUsuario.setText(usuarioLogado);
}

E no Frmlogin, no lugar de abrir o menu vazio, passe o e-mail digitado:

Frmlogin.java// login OK: abre o menu passando o e-mail e fecha a tela de login
new FrmMenu(email).setVisible(true);
this.dispose();
💡 Qual tela abre primeiro?
No arquivo Main.java (ou na classe com o método main), troque a tela que é aberta ao iniciar o programa pra Frmlogin, e não mais direto pro menu ou pra tela de clientes. 
Main.javapublic static void main(String[] args) {
    new Frmlogin().setVisible(true);
}

7 Desafio extra

Para fixar o conteúdo, proponho fazer o campo txtSenha chamar o método btnEntrarActionPerformed quando o usuário aperta Enter (evento keyPressed, verificando se evt.getKeyCode() == KeyEvent.VK_ENTER) — assim não precisa clicar no botão pra entrar.
